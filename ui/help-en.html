TTC450 · MKS DLC32 V2.1 · FluidNC + TS35 · web interface manual

1. Introduction and safety

This is the web interface for the TwoTrees TTC450 with an MKS DLC32 V2.1 board, FluidNC firmware and a TS35 panel. It replaces the stock WebUI, which cannot configure the console WebSocket in this build.

The page controls the machine over WiFi, shows live status and lets you send G-code, switch configs, edit settings, manage files and test the laser. Use the EN/PT button in the header to switch language.

Laser safety: use goggles rated for the wavelength, exhaust/air assist, a fire extinguisher and supervision. Never leave the laser unattended. The laser stays on until an M5; closing the browser does not turn it off.
Tool-change safety: power off the machine before swapping the spindle for the laser module (or vice versa). The laser goes only to the 3-pin TTL port (S/V/G); the spindle goes to the 2-pin CNC port.
Network: this page has no authentication. Do not expose it directly to the internet; use it only on the local network.

2. How the page talks to the machine

The board runs a WebSocket on port 80 at ws://192.168.15.77/ with the arduino subprotocol. On connect it sends currentID:N; that number is the PAGEID of the session.

  • Live status: <Idle|MPos:...|FS:...> and [GC:...] lines arrive over the WebSocket.
  • Commands/G-code: sent via /command?commandText=...&PAGEID=N; the response comes back over the WebSocket.
  • Queries: sent via /command?plain=... and return text directly (e.g. $I, $Settings/List, $Config/Dump).
  • Laser fallback: the page uploads a .nc file and runs it with $LocalFS/Run=.... This works even if the WebSocket drops.
Why the stock WebUI looks dead: it expects an [ESP...] line in $I to discover the WebSocket port; FluidNC does not send it and port 81 stays closed. The stock Terminal/buttons therefore do nothing.

3. Fundamental concepts

G-code and modal state

G-code is the machine command language. Each line changes a modal state: units (G20/G21), distance (G90/G91), coordinate system (G54…G59), motion (G0/G1), spindle/laser (M3/M4/M5), coolant (M7/M8/M9) and so on. The state persists until changed.

Coordinates: machine, work and WCO

  • MPos — machine position, referenced by homing/limits.
  • WPos — position in the work coordinate system (e.g. G54).
  • WCO — Work Coordinate Offset: the shift between machine and work. WPos = MPos − WCO.
  • DRO — digital readout: the X/Y/Z displays.

Homing, zero and limits

Homing ($H) finds the limit switches and sets the machine reference. Zero (G10 L20 P0 X0) defines the work zero. A limit can be hard (physical switch) or soft (software). In this config hard limits are enabled: the machine stops and enters Alarm; use $X/UNLOCK and jog away from the switch.

Feed, spindle and override

Feed is the cutting speed (F, mm/min). Rapid is fast positioning (G0). Spindle is the rotating tool; in laser mode the laser itself is the “spindle”. An override multiplies feed/rapid/spindle in real time without changing the G-code.

Alarm, ConfigAlarm and panic

Alarm is an error state (limit, probe, homing). ConfigAlarm is specific: the last boot was a panic and FluidNC came up with the Default (Test Drive) config. In that state G-code is blocked. A clean reboot ($Bye or the Restart button) loads the normal YAML again.

6. Control (generic motion)

This tab is mode-independent: it works in both CNC and laser. It has no tool buttons; only motion, coordinates, MDI and feed/rapid overrides.

This page is never locked by mode. To drive the tool, use the specific page.

Jog

Moves the machine in steps. Step is the increment (0.1, 1, 10, 100 mm or inches); Feed XY/Z is the speed. Each click sends $J=G91 G21 X1 F800 (example).

Zero and coordinates

Zero X/Y/Z/XY/XYZ sends G10 L20 P0 ... and sets the work zero. Go to X0 Y0 sends G90 G0 X0 Y0 (rapid; be careful).

Home and alarms

Home = $H; Home X/Y/Z = $HX/$HY/$HZ. Clear Alarm / Unlock = $X. In ConfigAlarm, use Restart, not $X.

MDI

Manual Data Input: type one or more G-code lines and send. Examples: G0 X10 Y10 F500, G10 L20 P0 X0, G1 X20 F300. Commands that look like the other mode ask for confirmation.

Feed and rapid overrides

Feed: −10/+10/−1/+1/reset. Rapid: 25/50/100%. Values appear in Ov:. The spindle override is on the spindle page.

Quick macros

Shows only generic macros (mode: any). Specific macros are on the CNC and Laser pages.

7. CNC (spindle, coolant, probe)

CNC-only page. If the current mode is not CNC, the whole page is locked (content inert) and only the “Switch to CNC” gate button works.

Spindle

In CNC mode gpio.32 goes to the 2-pin port (0–24 V relay). The 500 W spindle only turns on/off; rotation is set on the PSU potentiometer, not by software.

  • M3 S12000 — safely closes the relay (100%).
  • M3 S6000 — 50% PWM; the relay closes above ~12 V.
  • M5 — turns it off.
  • The 1/5/10/25/50/100% presets scale to 0–12000.

Diagnostics

The card shows PWM (pwm_hz/pin), speed map, off_on_alarm, hard/soft limits and MaxSpindleSpeed. When the page is locked these fields are unavailable.

Coolant

M7 mist, M8 flood, M9 off. On the TTC450 the pins are NO_PIN (not configured).

Spindle override

−10% / +10% / reset; the value appears in Ov:. Feed/rapid are on the Control tab.

Probe

The probe lowers Z with G38.2 until it touches the plate on gpio.22. Enter max travel, feed, plate thickness and retract. The page then applies G10 L20 P0 Z<thickness> and retracts.

CNC macros

Shows only macros with mode: cnc. Generic ones are in Control.

The gate is software protection: it does not change the cable, nor does it block external G-code. The physical tool swap is done with the machine powered off.

8. Laser (M3 fixed / M4 dynamic)

M3 alone is zeroed in FluidNC laser mode. A block M3 S50 without a feed move is treated as “laser off” and the firmware applies S0, even though the modal shows M3 S50. LightBurn works because it sends G1/G2/G3 ... S... with the move. The page sends G1 F100 M3 S... — that is why the web test works.

M3 fixed vs M4 dynamic

FluidNC supports M4 in laser mode. But M4 does not mean “continuous”:

ModeWhat it doesWhen to use
M3 fixedConstant power; PWM stays at the requested S.Focus, static test, simple cutting/engraving.
M4 dynamicPower proportional to speed; driven by motion (needs G1/G2/G3 with axes). It is zero when stationary.Engraving with smooth acceleration (LightBurn).

Use the M3 fixed / M4 dynamic toggle on the Laser tab. It is saved in the browser. The Pulse in M4 makes a short back-and-forth line in X so the laser actually fires; “Turn on (continuous)” in M4 is blocked because M4 does not emit while stationary. For jobs, prefer M4 in LightBurn/LaserGRBL.

Buttons

  • Pulse — M3: G1 F100 M3 S..., wait and M5. M4: G1 X... F100 M4 S... out and back, then M5.
  • Turn on (continuous) — M3: G1 F100 M3 S... and stays on until M5. M4: blocked (M4 needs motion).
  • LASER OFF — sends M5 immediately and also a fallback file.
  • Test 50% — 1 s M3 pulse to measure S/G with a multimeter.

Diagnostics

The tab shows the effective config: pwm_hz (1500), output_pin (gpio.32), speed_map, tool_num and off_on_alarm. If off_on_alarm is false, an alarm does not cut the laser automatically; use the red button. If the page is locked, the current mode is not laser: use the Dashboard/gate to switch.

If it does not fire: (1) confirm the machine is Idle, not Alarm/ConfigAlarm; (2) test 10%; (3) check TTL S/V/G, V=12/24 V, G=GND; (4) measure S-G during 50% (expect ~2.5 V average or 5 V PWM); (5) use the checklist on the Laser tab.

9. Modes and interlocks (Dashboard/Control/CNC/Laser)

The TTC450 uses one firmware and two YAMLs. The active mode changes pin gpio.32: in CNC it goes to the spindle relay (2-pin port, 0–24 V); in laser it goes to the TTL port (3-pin, 0–5 V). The physical cable decides which tool is connected.

The gate (lock)

When the mode does not match, the CNC or Laser tab content becomes inert (no button/input responds) and a banner shows the current mode with the Switch to CNC/laser button. The gate button and the top M5 stay active.

How to switch

Use the Machine mode card on the Dashboard (or the gate button). It writes $Config/Filename and restarts. You can also use $Config/Filename=... + $Bye in the console. Power off the machine before swapping the spindle cable for the laser (or vice versa).

Other protections

  • Macros: each macro has a Mode field (any/laser/CNC); macros of the other mode are disabled on the Macros page and blocked on execution.
  • Files: running a .nc with “laser” in the name in CNC mode (or “cnc/spindle” in laser mode) shows a warning first.
  • Console/MDI: commands that look like the wrong mode ask for confirmation.
  • M5 is always allowed: it is the spindle/laser safety stop.
The lock is software protection. It does not change the cable or block external G-code (LightBurn). The physical swap is your responsibility.

11. Settings

FluidNC Settings

Lists $Settings/List, grouped by prefix (Grbl, WiFi, Sta, AP, HTTP, Telnet, etc.). Edit a value and click Save. Some items require a reboot. Passwords are masked; leave blank to keep them.

WiFi

Shows $WiFi/Status and lets you change SSID, password, mode (STA, AP, STA>AP) and hostname. Save restarts the controller. WiFi is stored in NVS, not in the YAML.

Effective config

Shows $Config/Dump (the YAML actually loaded) and lets you download it. Use it to check Laser:, PWM:, pins and limits.

Firmware / OTA

Shows $Firmware/Info. OTA writes a .bin and restarts; do not power off during flashing. Use the correct image for DLC32 V2.1/8 MB.

Reports and preferences

Reports sets $Report/Interval (0 disables; 1000 ms default). Preferences changes units (mm/in), theme, poll interval, verbose and autoscroll. They are stored in the browser (localStorage).

12. Console

Sends $ commands and G-code. Commands go over the WebSocket (commandText + PAGEID); if the WS drops, the page tries plain for queries, but G-code needs the WS.

Shortcuts: $I, $G, $#, $State, $X, $H, $Settings/List, $Config/Dump, $WiFi/Status.

Verbose shows <...> status lines; Autoscroll follows the end; Filter hides lines that do not contain the text.

13. Macros

Each macro has a name, icon, color, type, mode and confirmation flag:

  • G-code — runs the lines (e.g. M5).
  • File — runs $LocalFS/Run=value.
  • URL — opens a link.

Macros are saved in /macros.json on LittleFS. The Save to machine button uploads the JSON. If the file does not exist, the page uses defaults.

Correct laser macro: G1 F100 M3 S50 + G4 P1 + M5 (do not use M3 S50 alone).

14. Camera and Tablet

Camera: enter an MJPEG/HTTP URL; the image appears in the tab. The camera is optional.

Tablet: large controls for DRO, jog, STOP, unlock, home and zero. Use Fullscreen to fill the display.

15. Troubleshooting

The laser does not fire from the web

  1. Confirm Idle; in ConfigAlarm or Alarm G-code is blocked. Restart (ConfigAlarm) or use $X (simple alarm).
  2. Test 10%; 1% may be below the module threshold.
  3. Use Pulse (the page sends G1 F100 M3 S...) — do not use M3 S... alone.
  4. Check TTL: S (PWM), V (12/24 V), G (GND), module powered and interlock.
  5. Measure S-G during the 50% test: ~2.5 V average or 5 V PWM. If 0 V, signal/config problem; if 5 V and no light, module/power.
  6. If LightBurn works and the web does not, it was the standalone M3 block — use the pulse/file G1.

M4 does not fire while stationary

M4 is dynamic power, not “continuous”. Stationary it is zero. Use M3 for a static test or the M4 Pulse (which makes a short line in X) / G-code with motion.

CNC (or Laser) page is locked

The page content is inert when the mode does not match: no button/input responds. The gate shows the current mode and the Switch to CNC/laser button. The lock is software only; it does not change the cable.

ConfigAlarm / “Default (Test Drive)”

The previous boot was a panic. FluidNC does not load the YAML and enters ConfigAlarm. Click Restart now in the banner or send $Bye. The YAML is not broken; the files are intact.

WebSocket offline

The red banner appears; the page reconnects every 2.5 s. $ queries may still work over HTTP; G-code/jog need the WS. The laser has a file fallback.

WiFi dropped

Check the 2.4 GHz network, the IP on the router and fluidnc.local. In STA>AP, if the network fails the board starts the FluidNC AP (password 12345678, IP 192.168.0.1).

Limit alarm / machine does not move

Check the limit switch, use $X/UNLOCK, jog away from the switch, then use $H. In this config hard_limits is on (recoverable stop); “Ambiguous switch” means the limit mapping is wrong.

Z drops when stopped

idle_ms is 255 ms to hold Z; “Motors OFF” disables the drivers and Z may drop.

Upload/file fails

Check LittleFS free space and the file name. Configs/UI/macros are protected from deletion. The SD card is not available in this build.

17. FAQ

Why is there no login?

This FluidNC build has authentication:no. Use it only on the local network.

Why does the laser work in LightBurn but not on the web?

LightBurn sends G1/G2/G3 ... S...; a standalone M3 S... is zeroed in FluidNC laser mode. The page now uses G1 F100 M3 S... via a file. With M4, LightBurn also sends motion; M4 stationary does not fire.

Does it support M4? Is M4 “continuous”? How do I switch?

Yes, M4 is supported. It is dynamic power (proportional to speed) and needs motion; M3 is fixed power. Use the M3 fixed / M4 dynamic toggle on the Laser tab. For jobs, prefer M4 in LightBurn/LaserGRBL.

Why is the CNC (or Laser) page locked?

Each page is exclusive to its mode. In laser mode the CNC page is locked; in CNC mode the Laser page is locked. Use the gate button or the Machine mode card on the Dashboard.

How do I switch between CNC and laser?

Dashboard → Machine mode, or $Config/Filename=... + $Bye. Power off the machine before changing the cable.

Why does 1% not fire?

Many modules have a minimum threshold. Test 5% or 10%.

What is ConfigAlarm?

Fallback after a panic. Restart; the normal YAML returns.

Can I use the TS35 panel and the web at the same time?

Yes, but avoid simultaneous commands. The panel and the web share the same state.

How do I restore the original WebUI?

The backup is in ui/webui-original.html.gz; upload it as index.html.gz and reload. See ui/README.md.

What is PAGEID?

It is the WebSocket session ID; commands are delivered only to the matching session. The page updates it automatically on reconnect.
